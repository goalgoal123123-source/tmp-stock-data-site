除 iwencai 外，其餘全部零鑒權 —— 無需註冊、無需 API Key。V3.8 的中證／國證／北交所，以及 V3.9 新增的 12 個來源（通達信官網、華爾街見聞、央視網、上證 e 互動、中債、中國貨幣網、五家期貨交易所、上金所）同樣免憑據（北交所用官網匿名 Cookie）。僅 iwencai 語義搜索需要 API Key（申請地址）。

數據源優先順序（按封 IP 風險）：1. 騰訊財經（首選，不封 IP） → 2. 交易所／官方機構（極低） → 3. 新浪／巨潮／同花順／百度／財聯社／華爾街見聞／央視網／申萬（低） → 4. mootdx／baostock（TCP；mootdx 2026-09 起行情命令失效，只用財務） → 末位：東財（有風控會封 IP，統一經 em_get() 限流）。
